This is the first post on my blog. I built it with [Astro](https://astro.build), published as Markdown right in this repository, and deployed on my homelab's Kubernetes cluster.

## What you'll find here

- Notes on personal projects and on [Sisques Labs](https://github.com/sisques-labs).
- How my homelab is put together: Proxmox, K3s, Argo CD, Cloudflare Tunnel...
- Things I learn (or break) along the way with DevOps, CI/CD, and self-hosting.

Every post is a Markdown file under `src/content/blog/`. If you're curious how it works under the hood, the code is at [github.com/JSisques/blog](https://github.com/JSisques/blog).
